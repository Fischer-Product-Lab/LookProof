# Security Policy

LookProof is pre-1.0 software. Only the latest `main` is supported for security fixes.

Report vulnerabilities directly through GitHub private vulnerability reporting at https://github.com/Fischer-Product-Lab/LookProof/security/advisories/new. Do not open a public issue.

Include a synthetic reproduction, the affected commit or version, the impact, and expected and actual behavior. Never include credentials, private artwork, provider payloads, or other sensitive content.

There is no response SLA and no security warranty.
